# -House-Price-Prediction-Using-Machine-Learning-Linear-Regression-Gradio


A Machine Learning project that predicts house prices based on different property features using **Linear Regression** and provides an interactive web interface using **Gradio**.

---

## 📌 Project Overview

House prices depend on several factors such as:

- Area of the house
- Number of bedrooms
- Number of bathrooms
- Number of stories
- Parking spaces
- Main road access
- Guest room availability
- Basement availability
- Hot water heating
- Air conditioning
- Preferred area
- Furnishing status

In this project, a **Linear Regression model** is trained on a house-price dataset to learn the relationship between these features and the house price.

The trained model is then connected to a **Gradio interface**, allowing users to enter property details and receive an estimated house price.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Understand a regression problem
- Load and explore a real-world dataset
- Prepare numerical and categorical features
- Train a Linear Regression model
- Make predictions on new house data
- Create an interactive Gradio interface
- Build a beginner-friendly end-to-end Machine Learning project

---
